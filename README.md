# TAL

*Mechanized Proof of _a_ Typed Assembly Language.*

Typed Assembly Language: TAL of Morrisett et al. [1] without existential types and where jumps specify a type for each register (and not just those that are going to be used). 

The mechanized proof has been obtained by editing the proof of <b>asm_jmp_bnz</b> that has been automatically generated by [Lang-n-Prove](https://github.com/mcimini/lang-n-prove-state/). We refer to <b>asm_jmp_bnz</b> as a "simple typed assembly language" (STAL) in the style of (and derived from simplification of) TAL [1] with addition/multiplication, load/store, move, malloc, conditional and unconditional jumps. 
<br>The mechanized proof <b>asm_jmp_bnz.thm</b> contains comments were modifications/additions have been needed.

[1] [From System F to Typed Assembly Language](https://www.cs.princeton.edu/~dpw/papers/tal-toplas.pdf). Greg Morrisett, David Walker, Karl Crary, Neal Glew. TOPLAS, Volume 21, Issue 3, Pages 527 - 568, 1999.


<br>
To manually check: 
<ul>
<li> Make sure you possess the Abella proof assistant tool in the version stated in the dependencies of <a href="https://github.com/mcimini/lang-n-prove-state/">Lang-n-Prove</a>.</li>
<li> For <b>asm_jmp_bnz</b>, run:   

  `abella asm_jmp_bnzUser.thm -c asm_jmp_bnzUser.thc ; abella asm_jmp_bnz.thm`
</li>
<li> For <b>tal</b>, run: 

  `abella talUser.thm -c talUser.thc ; abella tal.thm`
</li>
</ul>
